What is ISO 27001?

The global standard for information security management

70,000+

companies certified worldwide

Banks. Hospitals. Tech companies. Government agencies.
If you handle sensitive data, you need this.

Part of a large family

The ISO 27000 series has 20+ standards. These three are the core:

ISO 2700077 vocabulary terms
+
ISO 27001requirements
+
ISO 2700293 controls + guidance

ISO 27000 defines terms like "risk," "control," "vulnerability"
ISO 27001 states what you must do to get certified
ISO 27002 explains how to implement each control

Others: 27017 (cloud), 27018 (privacy), 27701 (privacy mgmt), 27005 (risk)...

Why hasn't anyone fixed this?

❌

Previous attempts used ontologies

Researchers built complex logical models.

Every time ISO published a new edition, everything broke.

Too rigid. Too fragile.

💡

My insight: use a taxonomy

ISO 27001 doesn't define logic rules. It's just concepts, labels, and cross-references.

A taxonomy is the right fit.

The tools I used

🧱

RDF

Resource Description Framework

A way to describe things as subject → predicate → object

"Access Control" → hasType → "Security Control"
"Access Control" → definedIn → "ISO 27002"
🗂️

SKOS

Simple Knowledge Organization System

A standard vocabulary for taxonomies built on RDF

prefLabel, definition, broader,
narrower, related, exactMatch...

What does it look like?

One concept from ISO 27002

iso27002:5.1 a skos:Concept ;
  skos:prefLabel "Policies for information security" ;
  skos:definition "Information security policy and topic-specific policies shall be defined..." ;
  skos:broader iso27002:Clause5 ;
  skos:exactMatch iso27001:A.5.1 .

Human-readable labels + machine-readable structure
